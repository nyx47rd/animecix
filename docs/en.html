AnimeciX

A desktop client for anime, series and movies on Linux. Built with GTK4/libadwaita, distributed as a single AppImage.

Download AppImage Source

Linux x86_64 · 4.6 MB · MIT License

Features

What it does

Home

Categorized lists for anime, series and movies. Horizontal shelves, large poster, short blurb. Click for details.

Episodes and player

MPV-based player. AniSkip auto-skips intros and outros. Anime4K shaders improve quality (Light, Ultra, Sharpening). Two-minute buffer, auto fullscreen.

Quick search

Press / from the home screen or Ctrl+S in the episode screen. All sources resolve in parallel; the highest-quality (by file size) wins. Dead sources are filtered; failures fall through to the next one.

Favorites, Marathon, History

Add titles to Favorites. Use Marathon for a watch-list with drag-and-drop ordering and per-episode progress. Watched episodes land in History automatically.

Settings and VPN proxy

Desktop launcher integration, shortcuts, data reset. If a SOCKS5 proxy is running on 127.0.0.1:10808 (e.g. sing-box + ProtonVPN), video traffic goes through it. Bypasses ISP restrictions. With no proxy, the app works as usual.

Install

Three ways to install

AppImage (recommended)

Single file, portable, no install required.

wget https://github.com/nyx47rd/animecix/releases/latest/download/AnimeciX-x86_64.AppImage
chmod +x AnimeciX-x86_64.AppImage
./AnimeciX-x86_64.AppImage

Desktop launcher

Open the app, then Settings → "Install to desktop" to add a .desktop file and app icon. Flatpak and AUR packages are planned; for now, only AppImage.

Dependencies (manual install)

Fedora

sudo dnf install gtk4 libadwaita mpv webkit2gtk4.1

Ubuntu / Debian

sudo apt install libgtk-4-1 libadwaita-1-0 mpv

Arch

sudo pacman -S gtk4 libadwaita mpv

The app checks for new versions on each launch. The AppImage build can self-update.

FAQ

Common questions

Playback stutters on slow internet. What can I do?

Settings → VPN Proxy: run a sing-box + WireGuard configuration on 127.0.0.1:10808. The app routes video traffic through that tunnel automatically. When the direct path returns 403 or a network error, the dual-path cascade mechanism falls back to the tunnel.

How do the Anime4K shaders work?

Settings → Display: pick from five modes — Off, Sharp (ewa_lanczossharp), Light (DTD), Ultra (CNN UL), and Light + Sharpening (DTD + unsharp filter). Light uses low GPU; Ultra maximizes quality.

Does it auto-update?

The AppImage build checks GitHub Releases on each launch. If a new version is available, a notification asks for confirmation. Disable via Settings → Auto-update.

Is this official?

No. AnimeciX is an unofficial third-party client. It uses a public API; use at your own responsibility, without harming the service provider.

Which distros are supported?

Any modern Linux with GTK4, libadwaita and MPV. Tested: Fedora 40+, Ubuntu 24.04+, Arch, openSUSE Tumbleweed, EndeavourOS.
