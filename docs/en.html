AnimeciX

A Linux desktop client for anime, series and movies.

Built with GTK4. Distributed as a single AppImage. Plays through MPV.

Download AppImage Source code

v3.0.0 · Linux x86_64 · 4.6 MB

Features

MPV playback

The player runs on MPV. AniSkip integration auto-skips intros and outros. Anime4K shaders improve image quality with five modes: Off, Sharp, Light (DTD), Ultra (CNN UL), and Light + Sharpening.

Two-minute video buffer reduces stuttering. Auto fullscreen, mouse-based volume and seek, subtitle management included.

Quick search

Press / from the home screen or Ctrl+S in the episode screen to search. All sources resolve in parallel; the highest-quality (by file size) is auto-selected.

Dead or passive sources are filtered out. If a chosen source fails to open, the next one is tried automatically.

Favorites, Marathon, History

Add titles to Favorites. Use Marathon to plan a watch-list with drag-and-drop ordering and per-episode progress. Watched episodes land in History automatically.

Settings and setup wizard

Desktop launcher integration, data reset, keyboard shortcuts. The setup wizard checks dependencies and installs a desktop entry.

VPN proxy option: if a SOCKS5 proxy is running on 127.0.0.1:10808 (e.g. sing-box + ProtonVPN), video traffic goes through it. With no proxy, the app works as usual.

Install

AppImage (recommended)

Single file, portable, no install required.

wget https://github.com/nyx47rd/animecix/releases/latest/download/AnimeciX-x86_64.AppImage
chmod +x AnimeciX-x86_64.AppImage
./AnimeciX-x86_64.AppImage

Flatpak

Available on Flathub.

flatpak install flathub io.github.nyx47rd.AnimeciX
flatpak run io.github.nyx47rd.AnimeciX

Dependencies

  • GTK4, libadwaita, MPV (≥ 0.36)
  • Fedora: sudo dnf install gtk4 libadwaita mpv webkit2gtk4.1
  • Ubuntu/Debian: sudo apt install libgtk-4-1 libadwaita-1-0 mpv

The app checks for new versions at startup. The AppImage build can self-update.

FAQ

Playback stutters on slow internet. What can I do?

Settings → VPN Proxy: run a sing-box + WireGuard configuration on 127.0.0.1:10808. The app routes video traffic through that tunnel automatically. When the direct path returns 403 or a network error, the dual-path cascade mechanism falls back to the tunnel.

How do the Anime4K shaders work?

Settings → Display: pick from five modes — Off, Sharp (ewa_lanczossharp), Light (DTD), Ultra (CNN UL), and Light + Sharpening (DTD + unsharp filter). Light uses low GPU; Ultra maximizes quality.

Does it auto-update?

The AppImage build checks GitHub Releases on each launch. If a new version is available, a notification asks for confirmation. Disable via Settings → Auto-update.

Is this official?

No. AnimeciX is an unofficial third-party client. It uses a public API; use at your own responsibility, without harming the service provider.

Which distros are supported?

Any modern Linux with GTK4, libadwaita and MPV. Tested: Fedora 40+, Ubuntu 24.04+, Arch, openSUSE Tumbleweed, EndeavourOS. The Flatpak build runs on any Flatpak-capable distro.
